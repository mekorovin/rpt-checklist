# Установка скрипта в Google Таблицу

Скрипт принимает чек-листы из формы и раскладывает их по колонкам.
Файл с кодом — [Code.gs](Code.gs).

## Перед началом

Проверьте, как называется лист, в который сейчас падают ответы (ярлычок внизу
таблицы). Скрипт пишет в лист с именем **«Ответы»**:

- лист называется иначе (`Лист1`, `Sheet1`) — ничего делать не нужно, скрипт
  создаст «Ответы» рядом, старые данные останутся нетронутыми;
- лист уже называется «Ответы» — **переименуйте его** в «Архив», иначе новая
  шапка ляжет поверх старой, а данные под ней окажутся не в своих колонках.

## 1. Открыть редактор

В таблице: **Расширения → Apps Script**. Откроется редактор с файлом `Код.gs`.

## 2. Заменить код

Выделить всё содержимое файла (`Ctrl+A`), удалить, вставить содержимое
[Code.gs](Code.gs) целиком. Сохранить — `Ctrl+S`.

## 3. Один раз запустить setupSheet

В верхней панели редактора выбрать в выпадающем списке функцию **`setupSheet`**
и нажать **«Выполнить»**.

При первом запуске Google попросит доступ:

1. «Требуется авторизация» → **Проверить доступы**;
2. выбрать свой аккаунт;
3. экран «Google не подтвердил приложение» → **Дополнительные настройки** →
   **Перейти на страницу «...» (небезопасно)**;
4. **Разрешить**.

Это разрешение на доступ к вашей же таблице — предупреждение появляется у любого
скрипта, не прошедшего публикацию в Google Workspace Marketplace.

После выполнения в таблице появятся листы **«Ответы»** (с шапкой и фильтром) и
**«Сводка»**.

## 4. Обновить развёртывание

**Развернуть → Управление развёртываниями** → выбрать активное развёртывание →
значок карандаша → в поле «Версия» выбрать **«Новая версия»** → **«Развернуть»**.

> Не нажимайте «Новое развёртывание» — оно выдаёт другой `/exec` URL, и его
> придётся менять в `src/App.jsx` и заново выкладывать сайт.

Проверьте, что адрес развёртывания совпадает с `GOOGLE_SCRIPT_URL` в
[../src/App.jsx](../src/App.jsx).

## 5. Проверить

Отправить тестовый чек-лист с сайта. В листе «Ответы» должна появиться строка:
дата отправки, поля формы, по две колонки на каждый критерий (оценка и
замечание), колонки «Проблем» и «Список проблем».

Если строка не появилась:

- лист **«Ошибки»** — туда пишутся падения скрипта вместе с исходным JSON;
- **«Выполнения»** в левом меню редактора — журнал запусков Apps Script.

## Если меняется список критериев

Порядок и состав `CRITERIA` в [Code.gs](Code.gs) обязан совпадать с
`RATING_CRITERIA` в [../src/App.jsx](../src/App.jsx) — иначе оценки лягут не в
свои колонки. После правки: заменить код (шаг 2), запустить `setupSheet` (шаг 3),
обновить развёртывание (шаг 4).

Оценки по неизвестным скрипту id не теряются — они попадают в колонку
«Оценки вне списка».
